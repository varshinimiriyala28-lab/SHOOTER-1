# 🚀 Space Shooter

A simple and interactive **Space Shooter web game** built using **HTML, CSS, and JavaScript**. This project is a web-based version of a beginner-friendly Python terminal Space Shooter game.

The player controls a spaceship, moves left or right, aligns with the enemy, and shoots to destroy it.

## 🎮 Live Gameplay

The game runs directly in a web browser without requiring Python or any external libraries.

## ✨ Features

* 🚀 Player spaceship
* 👾 Enemy spaceship
* ⬅️ Move left
* ➡️ Move right
* 🔫 Shoot at the enemy
* 🎯 Hit detection
* 💥 Enemy destruction
* 🏆 Score tracking
* ❤️ Player lives
* 🔄 Restart game
* ❌ Quit game
* ⌨️ Keyboard controls
* 📱 Responsive design
* 🌌 Space-themed interface
* ✨ Simple animations

## 🎮 Controls

| Key / Button  | Action        |
| ------------- | ------------- |
| `A`           | Move Left     |
| `D`           | Move Right    |
| `S` / `Space` | Shoot         |
| `Q`           | Quit          |
| ⬅️ Button     | Move Left     |
| ➡️ Button     | Move Right    |
| 🔫 Shoot      | Fire at Enemy |

## 🕹️ How to Play

1. Start the game.
2. Move the spaceship using the **A/D keys** or the buttons.
3. Align your spaceship with the enemy.
4. Press **S**, **Space**, or the **Shoot** button.
5. If aligned correctly, the enemy is destroyed.
6. If not aligned, the shot misses.
7. Try to achieve the highest score.

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the game
* **CSS3** – Provides the design, animations, and responsive layout
* **JavaScript** – Handles movement, shooting, collision detection, score, and game logic

## 💡 Original Python Version

The original game was created using basic Python concepts such as:

```python
player = 5
enemy = 3
```

The Python version used:

* Variables
* `while` loops
* `for` loops
* `if / elif / else`
* `input()`
* Basic game logic

The project was later converted into a browser-based game using **JavaScript** while maintaining the original gameplay concept.
